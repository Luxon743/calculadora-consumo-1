# 🚗 Registro de Viajes

Aplicación web para registrar cargas de combustible y calcular el consumo de un vehículo.

## 📌 Descripción

Permite ingresar kilometraje y litros cargados, guardar un historial de cargas y calcular el consumo promedio del viaje.

Los datos se almacenan en el navegador mediante LocalStorage, por lo que no se pierden al recargar la página.

---

## ⚙️ Tecnologías

* HTML
* JavaScript
* TailwindCSS

---

## 🚀 Funcionalidades

* Agregar cargas de combustible
* Visualizar historial de cargas
* Calcular consumo promedio (L/100km)
* Persistencia de datos con LocalStorage
* Reiniciar viaje

---

## 🖥️ Uso

1. Ingresar kilometraje y litros
2. Agregar cargas
3. Calcular el consumo del viaje
